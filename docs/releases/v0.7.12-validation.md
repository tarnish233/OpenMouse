## 设置窗口实际验证

候选代码已通过隔离的 `Open Mouse Debug.app` 运行。该 Debug 包包含本次蓝牙／Unifying 代码与 688 项自检，GUI 验证期间显示的旧包版本是 0.7.11 (21)；正式发布包的版本与构建号随后单独核对为 0.7.12 (22)，没有把调试包当发布资源。

测试前备份 Debug 偏好，临时关闭总开关与自动更新，避免与正在使用的正式实例争用鼠标；测试后确认 Debug 进程结束，并逐字节恢复原偏好。没有修改正式版配置或替换 `/Applications` 中的正式应用。

| 离开动作 | 取消 | 不保存 | 保存 |
|---|---|---|---|
| 切页 | 保留滚动页与草稿 | 恢复保存值后进入按键页 | 保存草稿后进入目标页 |
| 返回 | 保留正文、草稿与历史 | 放弃草稿后正确返回 | 保存后正确提交历史位置 |
| 关闭窗口 | 窗口与草稿保留 | 重开窗口恢复保存值 | 重开保留新值，保存反馈重置 |
| 退出应用 | 进程、窗口与草稿保留 | 进程结束，磁盘仍是保存值 | 进程结束，磁盘保存新值 |

12 个场景均通过真实界面操作及后续状态／磁盘读取确认。确认 sheet 实际可见、可响应，不仅检查按钮返回值。多显示器下自动化最初不能稳定取得辅助功能树，移动 Debug 窗口到主屏后完成了验证。

## 无法验证的部分

**没有 M720 与 Unifying 硬件，真实 USB/RF 链路仍未验证。** 接收器自检使用模拟 IO 驱动，虽然覆盖实际队列、接收器状态机、槽位隔离与退出恢复，仍不能证明鼠标固件实际接受命令。用户明确选择在无法实机回测的条件下发布；发布说明和 README 将该支持标注为实验性，并列明 C52B / C532、M720 WPID 405E、单一拇指键的范围。

# v0.7.12 — 罗技 M720 拇指键适配

## 实验性支持：M720 隐藏拇指键

> **这次适配没有经过 Open Mouse 的 M720 实机测试。** 蓝牙和 Unifying 路径依据公开协议、其他项目的设备报告实现，并通过模拟驱动回归检查；不能据此保证所有固件或连接方式都可用。欢迎反馈连接方式、接收器 PID、macOS 版本，以及是「录不到」还是「录得到但动作不执行」。

- 识别 M720 物理拇指控件 `0x00D0`，独立显示为「拇指键」，不会与前进键或 DPI 键共用绑定。
- 支持蓝牙直连的首次按键录入，可设置现有自定义快捷键、修饰键组合或手势导航。
- 新增受限 Unifying 路径：仅支持标准 `C52B / C532` 接收器，并确认槽位中的设备为 M720（鼠标类型、无线 ID `405E`）后才接管拇指键。
- 不向键盘槽位发 HID++ 2.0 控件查询，不打开接收器的普通键盘／鼠标接口。

## 稳定性处理

- 录入中途取消或删除绑定时清理可能丢失抬起的按住状态，避免下一次第一下失效。
- 接收器断连／换槽位按取消处理，不把丢失的抬起误判成一次调度中心单击。
- 接收器命令串行发送，按槽位和软件 ID 匹配回复，并提供有限的发现重试。
- 退出或停用时在私有 HID 队列恢复自己接管过的拇指控件；重新解析当前 feature index，避免旧恢复关闭新接管。

## 范围与使用要求

- Unifying 当前只接管同一接收器中一个 M720 的隐藏拇指键；普通侧键继续走原有 CGEvent 映射，不承诺接收器下的物理长按增强。
- **不包含 Bolt、Nano、Lightspeed、USB 有线或其他型号的接收器鼠标。** M750 的硬件 DPI 功能仍只走原有蓝牙路径。
- 请退出 Logi Options+ 等同类增强软件，给 Open Mouse 授予辅助功能和输入监控权限。输入监控授权后建议重启应用。
- 冷启动或刚唤醒时，先等待 HID++ 发现完成，再判断按键是否能录入。

详细适配与回测说明：[蓝牙路径](../m720-thumb-button.md)、[Unifying 路径](../m720-unifying.md)。

## 检查与签名

- 应用自检共 **688 项**，本次两阶段新增 117 项（蓝牙 34 项、Unifying 83 项）。
- 自动检查覆盖协议、模拟 IO 驱动下的真实队列／接收器状态机及动作路由，**不覆盖真实 USB/RF 链路**。
- 沿用固定社区证书与 hardened runtime，安装包仍未经过 Apple 公证。正常替换升级通常保留现有权限；支持固定社区身份的旧版本可通过应用内更新安装。
- 最低系统版本仍为 macOS 14；本次发布包为 Apple Silicon（arm64）。

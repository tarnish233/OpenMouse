# 其余设置页性能排查与回归（2026-09-28）

## 范围与结论

在按键页 DPI 缓存/异步查询的本地改动上，继续审查滚动、指针、应用、通用四页。没有改版本号、发布 Release 或替换已安装正式版。

| 页面 | 原路径 | 本轮处理 |
| --- | --- | --- |
| 滚动 | 绑定内存中的草稿、格式化数值 | 未发现进入页面的同类同步查询；不额外缓存配置或整页 |
| 指针 | 每次 onAppear 执行 reconcile，枚举设备并可能再次写入速度 | 进入时只展示已有快照；启动、偏好变化、热插拔及唤醒负责更新 |
| 应用 | AppIcon.body 同步查找应用路径、读取图标 | 串行 utility 队列加载；内存缓存，冷缓存显示占位，过期先显示旧图标 |
| 通用 | State 初始化和 onAppear 各读取一次登录项状态；诊断每半秒查目标进程名称 | 登录项异步读取并短期缓存；目标名称按 PID 缓存并监听进程生命周期 |

“添加应用/选择应用”的文件面板只有用户明确点击后才打开，不是进入设置页的加载路径，本轮不改。更新检查原有 async 流程及滚动对比参数更新也没有改写。缓存不复制用户草稿，保存/撤销仍操作唯一 SettingsStore。

## 失效与正确性约束

- 图标有效期 60 秒，缺失应用缓存 10 秒；重新激活应用时刷新规则图标，覆盖外部安装、移动和更新。最多缓存 128 个条目；可见行持有已加载图像，缓存淘汰不会抹掉当前图标，真实“应用缺失”结果会清除旧图标。
- 进程名称有效期 5 秒、缺失结果 1 秒，容量 64；只在请求的 PID 上读取，启动/退出通知使其失效，迟到回调不能污染复用的 PID。观察者不随页面消失，避免离页期间发生身份变化后沿用旧结果。诊断半秒计数刷新只格式化缓存文本。
- 登录项状态缓存 5 秒；冷状态未查明前禁用开关。进程级激活通知触发异步重读，覆盖从系统设置返回时的修改。读写确认带请求身份，重复/迟到结果不会覆盖新操作。
- 主动 register/unregister 保留原有同步提交语义，只有状态查询在后台；防止用户点击后立即退出应用，使系统更改停留在一个还没执行的工作队列中。测试没有实际更改登录项注册。
- 指针页不再触发设备应用。设备事件后的扫描完整运行约 0.4/1.2/3/6 秒的有限窗口，不能因已配置设备全部正常就忽略延迟发布的新设备；唤醒也安排该窗口，无永久轮询。
- 只有“上次已应用 + 当前真实读回一致”才跳过指针速度重复写入；新启用、偏好变化、外部修改、读回丢失、失败重试仍走原应用/确认路径。内容相同的设备快照不重复发布。

## 实际采样证据

环境：macOS 27.0、Xcode 27、M750 L 蓝牙。正式版只读采样捕获了进入通用页时的两处 SMAppService 同步查询，以及进入指针页时 reconcile。

另外使用隔离 Debug 包、相同四条临时规则（Finder、Safari、系统设置、未安装测试应用），对比修改前后的“通用 → 指针 → 应用”两轮切换。Debug 输入引擎关闭，正式版保持运行。

修改前样本：
- `AppIcon.body → AppIcon.icon → NSWorkspace.iconForFile / URLForApplicationWithBundleIdentifier` 在 Main Thread。
- `SMAppService.status` 在 Main Thread（初始化与 onAppear 两条路径）。
- `PointerSpeedController.reconcile` 在 Main Thread，来自进入指针页。

修改后样本：
- 图标路径/图标查询在 `com.openmouse.settings-metadata` 串行队列。
- 登录项状态查询在 `com.openmouse.login-item` 串行队列。
- 本轮切页采样未出现指针 reconcile 调用。

这是线程路径的前后验证，不将采样数换算成整页耗时，也不据此承诺所有环境下的加速百分比。

本机临时证据：`/private/tmp/openmouse-settings-perf/debug-before-active.sample.txt`、`debug-after.sample.txt`，不是发布资产。

- `make test`：535 项应用自检全部通过，本轮新增 46 项；更新助手、6 项发布签名、16 项社区签名、26 项构建元数据检查通过。
- `make debug`：固定社区身份签名、SDK/最低系统元数据校验通过；Swift 5 模式、最低 macOS 14 未改变。
- UI：相同规则重复进入三个页面，标题和侧栏选择一致；三个已安装应用的图标正常，未安装应用显示占位；通用页登录项读取完成后开关可用，未实际切换该系统设置；指针页仍显示 M750 L 与内建触控板。
- 草稿：在隔离 Finder 规则中选择自定义模式，切页出现确认；取消后仍在应用页且保留草稿，撤销后恢复原规则，随后正常进入通用/指针页。
- 新增自检覆盖 TTL 边界、负缓存、合并在途请求、失效后的迟到/重复响应、容量淘汰、登录项新旧请求竞态与失败恢复、指针重复写入防护。
- 没有为测试强制拔插鼠标或睡眠唤醒，因此真实热插拔/唤醒及实际登录项注册仍属于发布前硬件/系统回归范围；自检不替代这些验证。
- 测试完成后停止 Debug 并原样恢复其偏好。正式配置和 Karabiner 配置 SHA-256 与开始时一致。
